Core capabilities

FEATURE MAP
Dual-protocol server

HTTP/HTTPS and SOCKS5 listen simultaneously, covering different client needs.

Smart dual-track routing

VPN relay / direct egress, hot-switchable at runtime, auto-resets sockets without interruption.

Automatic NIC binding

Automatically detects hotspot, USB RNDIS, and Wi-Fi Direct, and binds the primary interface.

Seamless client onboarding

One-tap setup via QR code / PAC / WPAD, with illustrated guides for five platforms.

Connection management & protection

Device discovery, real-time rate limiting, temporary blocking, and username/password authentication.

Foreground keep-alive

A persistent foreground-service notification reduces the chance of aggressive ROMs killing the process.

Privacy policy

PRIVACY

Last updated: 2026-09-12

We collect no personal data

NetShare Proxy follows a "privacy-first, offline-first" design philosophy:

  • ✓ The app does not collect, store, or upload any personally identifiable information.
  • ✓ The app requires no account and contains no account system.
  • ✓ The app makes no data-reporting or telemetry requests to any server.
  • ✓ All network configuration, device lists, and statistics are stored locally on the device only and are cleared on uninstall.
  • ✓ Running as a local network relay, forwarded traffic is neither logged nor analyzed.

Permissions

  • Network access / foreground service: used to run the local HTTP/SOCKS5 proxy and keep the service resident.
  • Notifications: used to show the persistent foreground notification so you can switch modes or stop the service at any time.

Third parties & advertising

If a future version introduces advertising, the ad partners will be declared via app-ads.txt, and the corresponding data-processing details will be updated on this page at that time. The current version contains no third-party ad SDK.
